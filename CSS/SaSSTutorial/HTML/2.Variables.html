Sass Variables
With Sass, you can store information in variables, like:
  • strings
  • numbers
  • colors
  • booleans
  • lists
  • nulls
Sass uses the "$" symbol, followed by a name, to declare variables:
Sass Variable Syntax
$variablename: value;
Sass Variable Syntax
The following example declares 4 variables named myFont, myColor, myFontSize, myWidth
After the variables are declared, you can use them wherever you want 
                $myFont: Helvetica, sans-serif;
                $myColor: darkblue;
                $myBgColor: lightblue;
                $myFontSize: 18px;
                $myWidth: 680px;
                $myBorder: 1px red double;
                
                body {
                    background-color: $myBgColor;
                    font-family: $myFont;
                    font-size: $myFontSize;
                    color: $myColor;
                }
                
                #container {
                    width: $myWidth;
                    border: $myBorder;
                }

SaSS Variable Scope
Sass variables are only available at the level of nesting where they are defined.
Look at the following example (Mycolor.scss): 
                $myColor: red; //$myColor variable definition

                h1 {
                  $myColor: green; // Here we redefine $myColor variable
                  color: $myColor; 
                }
                
                p {
                  color: $myColor;
                }
the CSS output will be: 
                h1 {
                    color: green; // Scope is LOCAL
                  }
                  
                  p {
                    color: red;
                  }
Using Sass !global
The default behavior for variable scope can be overridden by using the !global switch.
!global indicates that a variable is global, which means that it is accessible on all levels.
                $myColor: red; //$myColor variable definition

                h1 {
                    $myColor: green !global; // Here we redefine $myColor variable as global
                    color: $myColor;
                }

                p {
                    color: $myColor;
                }
the CSS output will be: 
                h1 {
                    color: green; // Scope is local
                  }
                  
                  p {
                    color: green; // Scope is global
                  }
Tip for Global Variables in scss
Global variables should be defined outside any rules.
It could be wise to define all global variables in its own file, named "_globals.scss", and include the file with the @include keyword.
