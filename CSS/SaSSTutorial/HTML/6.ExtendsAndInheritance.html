@extend and Inheritance

@extend Directive
  • The @extend directive lets you share a set of CSS properties from one selector to another.
  • The @extend directive is useful if you have almost identically styled elements that only differ in some small details.
Defining @extend
This Sass example creates a basic style for buttons. Then, we create one style for "Report" button and one style for "Submit" button.
Both "Report" and "Submit" button inherit all the CSS properties from the .button-basic class, trough the @extend directive.
In addition, they've their own colors defined:
                .button-basic  {
                    border: none;
                    padding: 15px 30px;
                    text-align: center;
                    font-size: 16px;
                    cursor: pointer;
                    }
                    
                    .button-report  {
                    @extend .button-basic;
                    background-color: red;
                    }
                    
                    .button-submit  {
                    @extend .button-basic;
                    background-color: green;
                    color: white;
                    }
After the .scss transpiling the .css looks like this: 
                .button-basic, .button-report, .button-submit {
                    border: none;
                    padding: 15px 30px;
                    text-align: center;
                    font-size: 16px;
                    cursor: pointer;
                    }
                    
                    .button-report  {
                    background-color: red;
                    }
                    
                    .button-submit  {
                    background-color: green;
                    color: white;
                    }
