Divisiones (DIV) o Capas

DIV

La etiqueta DIV define una división; Una agrupación, un conjunto de elementos.
Permite agrupar varios elementos, por ejemplo, zonas o áreas de página independientes
Este tag se usa para estructurar el HMTL y aplicar CSS ya que el navegador no muestra nada con DIV, no tiene efecto por sí mismo.
También se muestra la manera más utilizada para ""centrar" un elemento en HTML "margin:auto"

Ejemplo con DIV
		
<style type="text/css">

	div.clase0  {
		background-color: olive;
		border: dotted 2px;
		color: white;
		padding-left:10px;
		width: 80%;
		margin: auto;
	}
	
	div.clase1 {
		background-color: black;
		color: white;
		width:20%;
		margin:auto;
	}
			
</style>
