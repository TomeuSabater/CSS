Visualización de Elementos

Display: none
El elemento queda oculto (también sus subelementos)
Es muy usado en JavaScript para hacer aparecer/desaparecer elementos
Display: inline
Los elementos se muestran sin romper la línea actual, de manera seguida.
permite colocar elementos de manera consecutiva, sin romper línea
se ignoran los márgenes superior e inferior (margin) pero sí reconoce
los rellenos (padding) y los márgenes superior e inferior, así como los bordes (border)
No hace caso de widht y height.
Por defecto son los elementos a, span, small, strong, em, mark, etc.
Display: block
Elementos que se muestran dentro de una caja rectangular.
Rompen la línea actual y, por defecto, no adminte otro elemento a su lado.
p, h1, h2, div, section, nav, figure, etc.
Display: inline-block
El elemento forma un bloque rectangular, per es interior a su contenedor (no rompe línea)
Sí admite elementos a su lado. Admite manipular width y heigh
Ejemplos son button, image, input, textarea, select, etc.
