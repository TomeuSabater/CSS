Visualización de Elementos

  • The "display" property is the most important CSS property for controlling layout.
  • The display property is used to specify how an element is shown on a web page.
  • Every HTML element has a default display value, depending on what type of element it is.
  • The default display value for most elements is "block" or "inline."
  • The display property is used to change the default display behavior of HTML elements.

Algunos de los atributos más comunmente utilizados para Display (no todos) son los siguientes:

Display: none

El elemento queda oculto (también sus subelementos)
Es muy usado en JavaScript para hacer aparecer/desaparecer elementos cambiando este atributo "display:none;" / "display:block;"

Display: inline

Los elementos se muestran sin romper la línea actual, de manera seguida o continuada
permite colocar elementos de manera consecutiva, sin romper línea
No hace caso de widht y height, pero el elemento afectado toma tanto widht como necesite.
Se aplica por defecto a los elementos: a, span, small, strong, em, mark, etc.

Display: block

Los elementos que se muestran dentro de una caja rectangular.
Rompen la línea actual y, por defecto, no adminte otro elemento a su lado, toma todo el width disponible
Se aplica por defecto a los elementos: p, h1, h2, div, section, nav, figure, etc.

Display: inline-block

El elemento forma un bloque rectangular, per es interior a su contenedor (no rompe línea)
Sí admite elementos a su lado. Admite manipular width y heigh
Ejemplos son button, image, input, textarea, select, etc.

Vamos a ver un ejemplo de todo lo anterior

	 	
<style type="text/css">

	p.clase0 {
		background-color: red;
		color:white;
	}
	
	p.clase1 {
		display:inline; /* No admite ancho ni alto, no agrega salto al final */
		background-color: red; /* El color de fondo sólo ocupa el espacio del texto */
		color:white;
	} 
	
	h3.clase2 {
		display: inline-block; /*Elemento de bloque pero va seguido */
		height: 50px;
		width: 30%;
		padding-top: 20px;
		background-color: olive;
	}


</style>
