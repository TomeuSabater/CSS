Formato de Fuentes

  • Existen diferencias en el modo en que los navegadores interpretan las reglas de estilo referente a las fuentes.
  • Además, existen muchas diferencias entre los valores que admite un tipo de fuente y otro.
    Por ejemplo: se pueden especificar hasta nueve valores de negrita (bold), pero muchas fuentes están diseñadas de tal forma que solo permiten ser visualizadas en dos valores: normal y negrita.
  • También hay que tener en cuenta que de nada sirve que especifiquemos una fuente especial, y maravillosa, si el usuario no la tiene instalada en su ordenador.

Google Fonts

If you do not want to use any of the standard fonts in HTML, you can use Google Fonts.
Google Fonts are free to use, and have more than 1000 fonts to choose from.

Just add a special style sheet link in the <head> section and then refer to the font in the CSS. Example:

<head>
<link rel="stylesheet" href="https://fonts.googleapis.com/css?family=Sofia">
<style>
		#id_1 {
	  		font-family: "Sofia", sans-serif;
		}
</style>
</head>
<body>
	<p id="id_1">This font is Sofia from Google Fons</p> 
</body>

This font is Sofia from Google Fons

To use multiple Google fonts, just separate the font names with a pipe character (|), like this:
<link rel="stylesheet" href="https://fonts.googleapis.com/css?family=Audiowide|Sofia|Trirong">

CSS Web Safe Fonts

Web safe fonts are fonts that are universally installed across all browsers and devices.
However, there are no 100% completely web safe fonts. There is always a chance that a font is not found or is not installed properly.
Therefore, it is very important to always use fallback fonts.
This means that you should add a list of similar "backup fonts" in the font-family property.
If the first font does not work, the browser will try the next one, and the next one, and so on. Always end the list with a generic font family name.
In the following example there are three font types: "Tahoma", "Verdan", and "sans-serif". The second and third fonts are backups, in case the first one is not found.

	p {
		font-family: Tahoma, Verdana, sans-serif;
	}

Propiedades de las Fuentes

Font-Family

Esta propiedad permite definir el tipo de letra.
Se pueden definir varias fuentes por si alguna de ellas no se encuentrara disponible para el navegador, se hace separando por coma todas las fuentes (se eligen de izquierda a derecha).
Algunas de las fuentes más comunes que puede acceder el navegador son: Arial, Arial Black, Arial Narrow, Courier New, Georgia, Impact, Tahoma, Times New Roman, Verdana.
Si la fuente no está disponible, el navegador selecciona el estilo por defecto.
Veamos un ejemplo:

<ul>
	<li style="font-family:Tahoma">Esto es Tahoma</li>
	<li style="font-family:Arial Rounded MT">Esto es Arial Rounded MT</li>
	<li style="font-family:Comic Sans MS">Esto es Comic Sans MS</li>
	<li style="font-family:Ink Free">Esto es Ink Free</li>
	<li style="font-family:Ink Journal, Ink Free">Esto es Ink Free, porque Ink Journal no la encuentra y aplica la primera</li>
	<li style="font-family:Whisper">Esto es una fuente de Google</li>
</ul>
  • Esto es Tahoma
  • Esto es Arial Rounded MT
  • Esto es Comic Sans MS
  • Esto es Ink Free
  • Esto es Ink Free, porque Ink Journal no la encuentra y aplica la siguiente
  • Esto es una fuente de Google
Font-Size
Esta propiedad modifica el tamaño de la fuente.
Se puede especificar de tres maneras:
  1. Usando palabras especiales que hacen referencia a tamaños predefinidos: 
    <li style="font-size:xx-small">Esto es xx-small, una fuente muy pequeña</li>
<li style="font-size:x-small">Esto es x-small, una fuente pequeña</li>
<li style="font-size:small">Esto es small, una fuente un poco pequeña</li>
<li style="font-size:medium">Esto es medium, una fuente de tamaño normal, el que aplica por defecto</li>
<li style="font-size:large">Esto es large, una fuente un poco grande</li>
<li style="font-size:x-large">Esto es x-large, una fuente grande</li>
<li style="font-size:xx-large">Esto es xx-large, una fuente muy grande</li>
    • Esto es xx-small, una fuente muy pequeña
    • Esto es x-small, una fuente pequeña
    • Esto es small, una fuente un poco pequeña
    • Esto es medium, una fuente de tamaño normal, el que aplica por defecto
    • Esto es large, una fuente un poco grande
    • Esto es x-large, una fuente grande
    • Esto es xx-large, una fuente muy grande
  2. Aumentando o disminuyendo el tamaño:
    En este caso se aumenta o disminuye el tamaño de la letra sobre el tamaño que le correspondería a la letra por defecto. Valores: 
    <li style="font-size:smaller">Tamaño disminuido sobre el tamaño por defecto</li>
<li>Tamaño normal que tiene el navegador por defecto</li>
<li style="font-size:larger">Tamaño aumentado sobre el tamaño por defecto</li>
    • Tamaño disminuido sobre el tamaño por defecto
    • Tamaño normal que tiene el navegador por defecto
    • Tamaño aumentado sobre el tamaño por defecto
  3. Modo exacto:

    En este caso se indica el tamaño de la letra con su valor numérico.
    Tras este número se indica la medida en la que se debe medir el número.
    Ejemplos: 12px, 2mm, 12pt, 1.2em, 120%

    <li style="font-size:100%">Tamaño a 100%</li>
<li style="font-size:15px">Tamaño a 15px</li>
<li style="font-size:1cm">Tamaño a 1 cm</li>
    • Tamaño a 100%
    • Tamaño a 15px
    • Tamaño a 1 cm
Font-Style

Esta propiedad asigna el Estilo de la fuente
Se permiten los siguientes valores:

<li style="font-style:normal">Normal: y se visualiza en modo normal que es el modo por defecto</li>
<li style="font-style:italic">Italic: y se visualiza en letra cursiva</li>
<li style="font-style:oblique">Oblique: el valor oblique visualiza una fuente aún más inclinada que la cursiva.<br> 
	(La diferencia entre italic y oblique pasará desapercibida en la mayor parte de las fuentes).</li>
  • Normal: y se visualiza en modo normal que es el modo por defecto
  • Italic: y se visualiza en letra cursiva
  • Oblique: el valor oblique visualiza una fuente aún más inclinada que la cursiva.
    (La diferencia entre italic y oblique pasará desapercibida en la mayor parte de las fuentes).
Font-Weight
El valor 'font-weight' determina el grosor de la fuente.
Los valores posibles son: 
<li style="font-weight:normal">normal: espesor normal. El valor por defecto</li>
<li style="font-weight:bold">bold: negrita</li>
<li>Valores numéricos: 100, 200, 300, 400, 500, 600, 700, 800, 900. 
	<br>Para que funcionen esos valores, debemos tener tipos de letra que incluyan esos grosores. 
	<br>El valor "normal" equivale a 400. 'Bold' equivale a 700.
</li>
<li style="font-weight:bolder">bolder: más gruesa. Aumenta el grosor actual de la letra (al siguiente disponible).</li>
<li style="font-weight:lighter">lighter: más delgada. Disminuye el grosor actual de la letra (al siguiente disponible).</li>
  • normal: espesor normal. El valor por defecto
  • bold: negrita
  • Valores numéricos: 100, 200, 300, 400, 500, 600, 700, 800, 900.
    Para que funcionen esos valores, debemos tener tipos de letra que incluyan esos grosores.
    El valor "normal" equivale a 400. 'Bold' equivale a 700.
  • bolder: más gruesa. Aumenta el grosor actual de la letra (al siguiente disponible).
  • lighter: más delgada. Disminuye el grosor actual de la letra (al siguiente disponible).
Font-Variant
Define si la fuente se muestra en mayúsculas tipo normal o pequeñas.
Los valores: 
<li style="font-variant:normal">normal: son letras normales</li>
<li style="font-variant:small-caps">small-caps: convierte las letras minúsculas en mayúsculas de un tamaño más pequeño que el normal. 
	<br>Si el tipo de fuente seleccionado no tiene versión smalls-caps, el navegador visualizará el texto en mayúsculas ordinarias.
</li>
  • normal: son letras normales
  • small-caps: convierte las letras minúsculas en mayúsculas de un tamaño más pequeño que el normal.
    Si el tipo de fuente seleccionado no tiene versión smalls-caps, el navegador visualizará el texto en mayúsculas ordinarias.
Font
Permite desde una sola propiedad cambiar de un solo golpe todas las anteriores.
Su sintaxis es: font: font-style font-variant font-weight font-size font-family
El orden tiene que ser estrictamente ese, pero algunas propiedades se pueden dejar sin utilizar.
Se requieren los valores "font-size" and "font-family, si se omite alguno de los otros valores se utiliza su valor predeterminado 
<p style="font:italic small-caps bold 26pt 'Comic Sans MS'">Ejemplo con cursiva y negrita de tipo Comic a 26 pt</p>
