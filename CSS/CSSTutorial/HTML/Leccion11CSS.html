Propiedades Relacionadas con las Listas

Se muestran, a modo de ejemplo, las posibilidades del CSS con los elementos HTML para crear listas

List Style

list-style-type

Permite especificar el tipo de elemento de numeración de la lista
Es recomendable que las <ol> muestren valores numerados
y que las <ul> muestre valores no numerados
Ejemplo:

	<style type="text/css">
		ol.armenian {list-style-type:armenian}
		ol.decimal {list-style-type:decimal}
		ol.decimal-leading-zero {list-style-type:decimal-leading-zero}
		ol.upper-roman {list-style-type:upper-roman}
		ol.lower-roman {list-style-type:lower-roman}
		ol.upper-alpha {list-style-type:upper-alpha}
		ol.lower-alpha {list-style-type:lower-alpha}
		
		ul.circle {list-style-type:circle}
		ul.square {list-style-type:square}
		ul.disc {list-style-type:disc}
		ul.none {list-style-type:none}
	</style>
	
	<ol class="armenian">
		<li>Esto</li>
		<li>es</li>
		<li>armenian</li>
	</ol>

list-style-image

Permite especificar una imagen para encabezar los elementos de la lista
La imagen debe ser de alguno de los formatos habituales (gif, jpg, jpeg, etc.) y tener en cuenta el tamaño de la imagen
Ejemplo

	<style type="text/css">
		ul.list-style-image {list-style-image:url("../PICS/sqpurple.gif")}		
	</style>
  • Esto
  • es
  • list-style-image
list-style-position

Permite especificar si los adornos están alineados con el texto o no

	<style type="text/css">	
		ul.outside {list-style-position:outside}
		ul.inside {list-style-position:inside}
	</style>

list-style

Permite con un solo tag especificar varios propiedades

<style type="text/css">	
	ul.list-style {list-style: square inside}
</style>

CSS Vertical Navigation Bar

A navigation bar needs standard HTML as a base.
In our examples we will build the navigation bar from a standard HTML list.
A navigation bar is basically a list of links, so using the <ul> and <li> elements makes perfect sense:

STEP 1

construiremos la Nav Bar paso a paso
comenzamos mediante una lista no numerada sin ningún tipo de formato:

<ul>
  <li><a href="default.asp">Home</a></li>
  <li><a href="news.asp">News</a></li>
  <li><a href="contact.asp">Contact</a></li>
  <li><a href="about.asp">About</a></li>
</ul>
  • Home
  • News
  • Contact
  • About

STEP 2

Siguiente paso será remover los "bullets", el "margin" y el ""padding" de la lista

<style type="text/css">
	ul.navbar {
		list-style-type: none; 
		margin: 0; 
		padding: 0; 
	}
</style>	
	
<ul class="navbar">
  <li><a href="default.asp">Home</a></li> 
  <li><a href="news.asp">News</a></li>
  <li><a href="contact.asp">Contact</a></li>
  <li><a href="about.asp">About</a></li>
</ul>
  • Home
  • News
  • Contact
  • About

"list-style-type: none;" - Removes the bullets. A navigation bar does not need list markers
Set "margin: 0;" and "padding: 0;" to remove browser default settings

STEP 3

To build a Vertical Navigation Bar, you can style the <a> elements inside the list, in addition to the code from the previous steps

<style type="text/css">

	ul.navbar {
  		list-style-type: none; 
  		margin: 0; 
  		padding: 0; 
	}

	li a.navbar {
		display: block;
		width: 60px;
		background-color: #dddddd;
	}
	
</style>

<ul class="navbar">
  <li><a class="navbar" href="default.asp">Home</a></li>
  <li><a class="navbar" href="news.asp">News</a></li>
  <li><a class="navbar" href="contact.asp">Contact</a></li>
  <li><a class="navbar" href="about.asp">About</a></li>
</ul>
  • Home
  • News
  • Contact
  • About

A background color is added to the links to show the link area.
Notice that the whole link area is clickable, not just the text.

"display: block;" - Displaying the links as block elements makes the whole link area clickable (not just the text), and it allows us to specify the width (and padding, margin, height, etc. if you want)
"width: 60px;" - Block elements take up the full width available by default. We want to specify a 60 pixels width

STEP 4

You can also set the width of <ul>, and remove the width of <a> as they will take up the full width available when displayed as block elements.
This will produce the same result as our previous example

We will create a basic Vertical Navigation Bar with a gray background color and change the background color of the links when the user moves the mouse over them

In this example, we also create an "active" class with a green background color and a white text. This class is added to the "News" link.
This could be the page you're, so you have the Navigation Bar, and the Active Page when you are located

<style type="text/css">

ul.navbar2 {
	list-style-type: none;
	margin: 0;
	padding: 0;
	width: 200px;
	background-color: #f1f1f1;
}

li a.navbar2 {
	display: block;
	color: #000;
	padding: 8px 16px;
	text-decoration: none;
}

/* Change the link color on hover */
li a.navbar2:hover {
	background-color: #555;
	color: white;
}

li a.active {
	display: block;
	background-color: #04AA6D;
	color: white;
	padding: 8px 16px;
	text-decoration: none;
}
	
<ul class="navbar2">
	<li><a class="navbar2" href="#home">Home</a></li>
	<li><a class="active" href="#news">News</a></li>
	<li><a class="navbar2" href="#contact">Contact</a></li>
	<li><a class="navbar2" href="#about">About</a></li>
</ul>
	
</style>

STEP 5

In this example, we will apply some refinement. We center the navigation links and add a border to the navigation bar.

<style type="text/css">	
ul.navbar3 {
	list-style-type: none;
	margin: 0;
	padding: 0;
	width: 200px;
	background-color: #f1f1f1;
	border: 1px solid #555;
}

li a.navbar3 {
	display: block;
	color: #000;
	padding: 8px 16px;
	text-decoration: none;
	text-align: center; 
	border-bottom: 1px solid #555;
}


li a.active3 {
	display: block;
	background-color: #04AA6D;
	color: white;
	padding: 8px 16px;
	text-decoration: none;
	text-align: center; 
	border-bottom: 1px solid #555;
}

#navbar3 {
	border-bottom: none;
}

/* Change the link color on hover */
li a.navbar3:hover {
	background-color: #555;
	color: white;
}

/* Change the link color on active */
li a.navbar3:active {
	background-color: #f00;
	color: white;
}
	
<ul class="navbar3">
	<li><a class="navbar3" href="#home">Home</a></li>
	<li><a class="active3" href="#news">News</a></li>
	<li><a class="navbar3" href="#contact">Contact</a></li>
	<li><a class="navbar3" id="navbar3" href="#about">About</a></li>
</ul>
</style>

Add text-align:center to <li> or <a> to center the links.
Add the border property to <ul> add a border around the navbar. If you also want borders inside the navbar, add a border-bottom to all <li> elements, except for the last one
