CSS Introducción

CSS

Cascade Style Sheets (Hojas de Estilo en Cascada) que se denomina así

  • Lenguaje de texto que se incrusta en las páginas web para dar formato a la página
  • Actúa sobre los elementos HTML definiendo la forma y estilo en la que se mostrarán en pantalla.
Versiones de CSS

CSS se ideó a mediados de los años '90 y se ha ido estandarizando. Se habla de tres versiones de CSS:

  • CSS1. Versión original de CSS. Estandarizada en 1996 por la W3C (https://www.w3.org/ organismo de estándares oficial de Internet)
    incluye formatos de texto, párrafo, márgenes, lista, tamaños de imágenes,…
  • CSS2. Es estándar desde 1998. Amplía el CSS anterior para incluir sobre todo posicionamiento (manejo de capas).
  • CSS3. Es la última evolución del lenguaje de las Hojas de Estilo en Cascada, y pretende ampliar la versión CSS2.
HTML + CSS + JavaScript

Una buena página Web contendrá código HTML5 + CSS3 + JavaScript, no obstante cada lenguage debe ser responsable de un aspecto de la página
Se aconseja estructurarla de la siguiente manera:

  • Código HTML5 para el contenido (información) y estructura, QUÉ se muestra
  • Código CSS3 para el formato de la información o presentación, CÓMO se muestran
  • Código JavaScript para dotar de dinamismo a la información, se consigue que la página no se presente de manera estática y tenga un COMPORTAMIENTO
  • Ejemplo: Una imágen es el QUE, en formato de tumbnail es el COMO, y si se sitúa el cursor encima se muestra en tamaño original sería el COMPORTAMIENTO

CSS Sintaxis Básica

La Sintaxis Básica del CSS depende de la forma en la que se inserta el código en la página HTML.
Hay 3 formas diferentes:

  • Definición de estilos a nivel de etiqueta: Inline CSS
  • Definición de estilos a nivel de página: Internal CSS
  • Definición de estilos en un fichero externo: External CSS
Definición de estilos a nivel de etiqueta, Inline CSS
  • El código CSS se aplicará a la etiqueta en la que se ha incluido dicho código.
  • El resto del documento no queda afectado por el código CSS.
  • En esta forma se añade un nuevo atributo denominado "style" a una etiqueta HTML.
  • La sintaxis para añadir el atributo "style" a un tag HTML es la siguiente:
    <etiqueta_html style="propiedadCSS:valor; propiedadCSS:valor; …">
  • La forma de definr CSS a nivel de etiqueta no es la más óptima porque mezcla HTML y CSS
    Se suele usar de manera puntual para sobreescribir el CSS definido a nivel de página
Definición de estilos a nivel de etiqueta, ejemplo:
<!DOCTYPE html>
<html lang="es">
	<head>		
	  <meta charset="utf-8">	
	  <title>CSS Leccion 1 - Introducción CSS</title>
	</head>		
	<body>
		<p style="color:#ff0000;background-color:#ffff00">Esto es un párrafo con formato CSS</p>
		<p style="color:#ffffff;background-color:#000000">El estilo del párrafo anterior no afecta a este párrafo</p>
	</body>
</html>
