Dando Formato al Texto

CSS has a lot of properties for formatting text.

Color del Texto

Color del Texto

Permite definir el color del texto.
El color se puede especificar mediante

  • Nombre, por ejemplo "red"
  • Codificación en RGB Hexadecimal, ejemplo "#ffff00", que sería amarillo
  • Codificación RGB Decimal, ejemplo "rgb(0,255,0)", quer sería verde
<li style="color:red">Este texto es de color rojo</li>
<li style="color:#ffff00">Este texto es de color amarillo</li>
<li style="color:rgb(0,255,0)">Este texto es de color verde</li>
  • Este texto es de color rojo
  • Este texto es de color amarillo
  • Este texto es de color verde

<li style="text-align: right">right: Aquí el texto está alineado a la decha.</li>
<li style="text-align: center">center: Aquí el texto está alineado al centro.</li>
<li style="text-align: justify">justify: Aquí el texto está justificado.</li>

Text Decoration

Text Decoration

Permite decorar el texto añadiendo una línea
por ejemplo, que el texto aparezca subrayado o con una línea en la parte superior

  • "text-decoration-line": This property is used to add a decoration line to text.
  • "text-decoration-color": Specify a color for the decoration Line
  • "text-decoration-style": This property is used to set the style of the decoration line.
  • "text-decoration-thickness": This property is used to set the thickness of the decoration line.
  • "text-decoration": This property is a shorthand property for: line (required), color, style and thickness
  • "text-decoration: none": All links in HTML are underlined by default. The "text-decoration: none" is used to remove the underline from links
<li style="text-decoration: none">none: sin subrayado, muy útil para eliminar el subrayado por defecto en los enlaces</li>
<li style="text-decoration-line: underline">underline: subrayado debajo</li>
<li></li>
<li style="text-decoration-line: overline">overline: subrayado encima</li>
<li style="text-decoration-line: line-through">line-through: tachado</li>
<li style="text-decoration-line: underline; text-decoration-color:red">Subrayado y en rojo</li>
<li style="text-decoration-line: line-through; text-decoration-color:green">Tachado en verde</li>
<li style="text-decoration-line: underline; text-decoration-style:wavy">Subrayado debajo ondulado</li>
<li style="text-decoration: underline red dotted">Subrayado debajo con puntos y rojo</li>
  • none: sin subrayado, muy útil para eliminar el subrayado por defecto en los enlaces
  • underline: subrayado debajo
  • overline: subrayado encima

Text Transformation

Text Transformation

Permite cambiar el texto a mayúsculas o minúsculas.
Admite los siguientes valores con alguno de los siguientes valores:

<li style="text-transform: capitalize">capitalize: Dispone en mayúsculas el primer carácter de cada palabra</li>
<li style="text-transform: lowercase">lowercase: CONVIERTE EN MINúSCULAS TODO EL TEXTO</li>
<li style="text-transform: uppercase">upercase: convierte en mayúsculas todo el texto</li>
<li style="text-transform: none">none: No Provoca Cambios en el TEXTO</li>
  • capitalize: Dispone en mayúsculas el primer carácter de cada palabra
  • lowercase: CONVIERTE EN MINúSCULAS TODO EL TEXTO
  • upercase: convierte en mayúsculas todo el texto
  • none: No Provoca Cambios en el TEXTO

Text Spacing

Text Indentation

Permite definir la sangría de un bloque de texto.
Los valores admitidos son unidades de longitud.
Podemos indicar un valor negativo con lo que la sangría es hacia la izquierda.

<p style="text-indent:+2em">Esto es la primera línea sangrado +2em la segunda ya no sangra
	<br>Esta es la segunda línea ya no debería sangrar. 
</p>
<p style="text-indent:-2em">Esto es la primera línea sangrado -2em la segunda ya no sangra
	<br>Esta es la segunda línea ya no debería sangrar. 
</p>

Text Shadows

Text-shadow

Permite generar una sombra al texto para darle efecto de volumen.
Tiene esta sintaxis: text-shadow: color distanciaX distanciaY desenfoque;

  • distanciaX: Es el desplazamiento horizontal que tendrá la sombra (puede ser positivo o negativo)
  • distanciaY: Es el desplazamiento vertical que tendrá la sombra (puede ser positivo o negativo)
  • desenfoque: Es opcional e indica cuánto se va a desenfocar la sombra. Se indica una cantidad que cuanto mayor sea, más desenfocará el fondo.
  • color: Es el color de la sombra.
<p style="text-shadow: 2px 2px 5px red">Ejemplo 2px 2px 5px red</p>
