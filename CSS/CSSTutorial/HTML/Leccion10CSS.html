Herencia de Estilo, Estilo en Función del Contexto, Clases y Pseudo Clases de Estilos

Herencia de los Estilos

Todas las Etiquetas contenidas "dentro" de otras etiquetas heredan los estilos.
por ejemplo, si en <body> tenemos "background-color = red" todos los tag
tendrán es mismo color de fondo, a no ser que lo redefinamos en cada tag.
Veamos un ejemplo con <li> conteniendo un <span>

	<li style="color:green">Verde como color de fondo excepto <span style="color:red">estas palabras en rojo</span></li>
  • Verde como color de fondo excepto estas palabras en rojo
Definición de un Estilo en Función del Contexto

En CSS es posible definir un estilo para un tag HTML con la condición de que
este tag esté contenido dentro de otro. Es una manera de definir estilos solo cuando ocurre una combinaciones de marcas.
Ejemplo:

	<style type="text/css">
	
		li  {color:red}	
		li span {color:green}
		</style>
		
	<li>Este <span>li</span> es <span>rojo</span> pero solo cuando esté en combinación con <span> es <span>verde</span></li>
  • Este li es rojo pero solo cuando esté en combinación con <span> es verde
Defición de Estilos Mediante Clases (recordatorio)

Hasta ahora, hemos visto como el estilo se aplica a un tag HTML
Con el concepto de "Class" podemos aplicar el estilo a varias marcas al mismo tiempo.
Una ""Class"" es una regla de estilo con un nombre. La sintaxis es como sigue ".nombre_de_clase"
Para luego aplicarlo dentro de la marca se especifica "class=nombre_de_clase"
Ejemplo:

	<style type="text/css">
	
		li  {color:red}	
		
		li.clase1 {
				color:white;
				background-color:#D3D3D3
				}
		
		li.clase2 {
				color:white;
				background-color:#000000 
				}
						
	<li>Este li es color rojo</li>
	<li class="clase1">Esto es li afectado por clase1</li>
	<li class="clase2">Esto es li afectado por clase2</li>
		
	</style>
  • Este li es color rojo
  • Esto es li afectado por clase1
  • Esto es li afectado por clase2

Pseudo Clases

Las Pseudoclases son Clases Especiales que se definen añadiendo dos puntos antes de la pseudoclase concreta
La sintaxis es la siguiente; etiqueta:pseudoclase{propiedad}
Las más usadas son las que se usan con <a>
Es importante saber que el orden en que se definen la pseudoclases es fundamental
Orden: link-visited-hover-active
Veamos las más importantes:

:link
Enlace sin visitar
:visited
Enlace visitado
:hover
Enlace con el mouse sobre él
:active
Es la que tiene el foco en ese momento
:first-letter
Primera letra del texto
:first-line
Primera línea de texto
:first-child :last-child
Hace referencia al primer/último elemento de un tipo contenido dentro de otro.
Es necesario que el tipo del primer/último elemento sea el indicado en la hoja de estilo
Es decir, debe ser el primer/último hijo para que se aplique la propiedad.
:nth-child(number)
Represente el elemento cuya posición sea = number
:nth-child(3) Representa el tercer hijo
:nth-child(odd)
Representa elementos cuya posición numérica es impar; 1, 3, 5, etc
:nth-child(even)
Representa elementos cuya posición numérica es par: 2, 4, 6, etc
:nth-child(An+B)
Representa elementos cuya posición nunérica coincide con el patrón An+B, para cada entero positivo
(5n) = 5*1 = 5, 5*2 = 10, 5*3 = 15, etc.
(3n+4) = 3*0+4 = 4, 3*1+4 = 7, etc.
