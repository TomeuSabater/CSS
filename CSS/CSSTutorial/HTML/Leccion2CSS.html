Definición de estilos a nivel de página, Internal CSS

Se puede definir un estilo para que afecte a todos los tag de una página
para ellos, usamos los tag <style></style> en la cabezera del documento

La etiqueta <style> tiene el atributo type, que permiten al navegador identificar el tipo de código que contiene.
Se usa “text/css”. Se puede observar que en la cabecera de la página se define la sección:

Definición de estilos a nivel de página ejemplo
		<head>
		
		  <title>CSS Leccion 2, CSS a nivel de página</title>
		  <meta charset="utf-8">
		  <meta name="viewport" content="width=device-width, initial-scale=1">
		
		  <style type="text/css">
			h2 {
				color:#ff0000;
				background-color:#ffff00;
			}
			h4 {
				color:#00ff00;
			}
		  </style>
		
		</head>

Ahora todos los h2 se escriben en rojo y fondo amarillo

Esto es h3, por tanto no está afectado por ningún estilo

Esto es h4, por tanto, afectado por un estilo

Esto es h5, por tanto, no afectado
