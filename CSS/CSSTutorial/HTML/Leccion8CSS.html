Propiedades de los Fondos

Color de fondo (background-color / Opacity - Transparency)

La propiedad "background-color" permite establecer un color de fondo al elemento al que se aplique la propiedad.
Si se aplica al elemento body, toda la página tendrá ese color de fondo;
aplicado a otro elemento, por ejemplo un <p>, el elemento tendrá como fondo el color aplicado.
Recordar que el color se puede especificar en nombre "red", valor exadecimal "#ffffbc", o en RGB "rgb(255,0,0)"
También se puede aplicar una "opacity" especificando una opacidad/transparencia al elemento
El valor "opacity" puede ser desde 0.0 o completamente transparente, a 1.0 completamente opaco
Este valor se puede modificar con JavaScript generando un efecto interesante

<p style="background-color:black;color:white">Este párrafo tiene un fondo negro y un texto de color blanco</p>
<h1 style="background-color:green;opacity:0.1">opacity=0.1</h1>
<h1 style="background-color:green;opacity:0.6">opacity=0.6</h1>
<h1 style="background-color:green;opacity:1.0">opacity=1.0 (default value)</h1>

Se observa que la opacidad también se aplica a todos los elementos denttro del tag, incluído el texto
Se puede evitar este efecto, aplicando solamente opacidad al fondo, mediante el uso de la codificación RGB(red,green,blue,opacity)

<h1 style="background-color:rgb(0,255,0,0.3)">opacity=0.3</h1>

Imagen de fondo

La propiedad "background-image" permite establecer una imagen de fondo.
Esta imagen se superpone al color de fondo si lo hay, de modo que si la imagen no se puede cargar, por ejemplo porque la ruta no es correcta, entonces aparece el color de fondo.
Por defecto, la imagen de fondo se repite las veces necesarias, creando un mosaico, tanto en horizontal como en vertical, hasta que se rellena el elemento.

<div style="background-image: url('../PICS/BackgroundPaper.jpg')">Este texto está dentro de un div para probar el tag de fondo</div>
Este texto está dentro de un div para probar el tag de fondo

La propiedad "background-repeat" repite la imagen en horizonal o vertical, o se elimina su repetición para que haya una sola

  • repeat-x / repeat-y. Repetición de la imagen en eje-X / eje-Y
  • no-repeat. Solamente e muestra la imagen una vez.

La propiedad "background-position" permite especificar la posición de la imagen

La propiedad "background-attachment" permite especificar si la imagen es fija o se debe desplazar con el scroll de pantalla

  • scroll. Valor por defecto. El fondo y el texto se mueven juntos cuando el usuario se desplaza por la página
  • fixed. El fondo es fijo y solo se mueve el texto.

Ejemplo de todo lo anterior:

<style type="text/css">
	body {
		background-color: #d3d3d3; /* Gris claro */
		background-image: url("../PICS/Green-leaft.gif"); /* Imagen de fondo */
		background-repeat: no-repeat; /* No se repite, imagen sólo una vez */
		background-position: top right; /* Arriba a la derecha*/
		background-attachment: fixed; /* No se desplaza con la página*/
	}	
</style>

Se puede resumir todos los parámetros anteriores en una única propiedad "background"
"background: #ffffff url("img_tree.png") no-repeat right top;"
