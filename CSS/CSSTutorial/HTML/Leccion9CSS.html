The CSS Box Model / Modelo de Cajas o Bloques del CSS

El CSS Box Model es esencial para entender la estructura y composición de los elementos en CSS

El navegador estructura la información en bloques (cajas).
El bloque principal es el que forman las etiquetas "<body> </body>".
El bloque <body>, a su vez, contiene subloques formados por las otras etiquetas como <p></p>, <h1></h1>, <div></div>, <li></li>
Por defecto, el navegador muestra los elementos como rectángulos (cajas) y con una formato y tamaño predefinido.

Estructura del Bloque / Caja

Composición de la Caja o Box Model
  • Content: En el centro del bloque está el Contenido o Content. Es La informació que se visualiza, básicamente texto e imágenes. En el gráfico se identifica como "Content".
  • Padding: Alrededor del Contenido existe un área denominada Padding, o relleno, que se extiende hasta el Border. En el gráfico es el área de color verde alrededor del contenido.
  • Border: El Border es la línea que separa el Content y su área de Padding de los márgenes. En el gráfico es el borde de color amarillo.
  • Margin: El Márgen o Margin es el espacio entre el Border del bloque, y el Border de otros bloques, los Margin se situan fueran de los Border y son la parte más externa del bloque.
  • El Box Model nos permite definir las características (mayormente el grosor) del Padding, Border y Maring, permitiendo definir el espacio entre los elementos de una página. El ancho de los Padding, Border (también la forma y color) y Margin pueden ser diferente en cada lado del bloque para un mismo bloque.
  • Cuando definimos las propiedades (width & height) con CSS, se aplican únicamente al Content. Para calcular el total de width & height de hay que tener en cuenta todos los elementos; Padding, Border y Margin

Modelo visual de Bloque o Caja:

Border

Border (Bordes)

Sabemos que el borde es la línea que separa los márgenes del padding.
Hay tres características esenciales de los bordes que pueden ser definidas:

  • Border-color (color del borde): Que se puede asignar de cualquiera de las formas vistas anteriormente.
    Podemos modificar independientemente cada uno de los cuatro bordes: border-top-color, border-right-color, border-bottom-color, border-left-color
  • Border-width (anchura) y los posibles valores son:
    • thin: borde fino.
    • medium: borde de grosor medio
    • thick: borde grueso
    • También pueden usarse porcentajes o indicar unidades de medida (px, pt, cm, em, etc.)
  • Border Style (estilo del borde) los posibles valores son:
    • solid: borde sólido
    • dashed: borde rayado
    • dotted: borde punteado
    • double: borde doble
    • groove: borde 3D con efecto de hundimiento
    • ridge: borde 3D con efecto de elevación
    • inset: efecto 3D
    • outset: efecto 3D
    • hidden: Oculto
    • none: Sin borde

Las tres características vistas se pueden combinar y de manera independiente para cada borde.
por ejemplo, border-top-width, border-top-color, border-top-style definiría la anchura, color y el estilo del borde superior

También Se puede indicar las propiedades vistas de manera abreviada:

  • border-right: Permite indicar a la vez las tres propiedades del borde derecho
  • border-top: Permite indicar a la vez las tres propiedades del borde superior
  • border-left: Permite indicar a la vez las tres propiedades del borde izquierdo
  • border-bottom: Permite indicar a la vez las tres propiedades del borde inferior

Finalmente, con "border : width style(required) color" se puede indicar la propiedad de manera abreviada para los cuatro bordes

Veamos algunos ejemplos:

<style type="text/css">

	h2.border_1 {
		border-top:green 5px dotted;
		border-right: 3px double;
		border-bottom: 10px solid blue;
	}
	h3.border_2 {
		border-width: 5px;
		border-style: groove;
		border-color: olive;
	}
	
</style>

Border-radius (Bordes redondeados)

En CSS3 existe la posibilidad de crear bordes redondeados, las esquinas de los bordes pueden formar un radio de un círculo cuyo tamañoo podremos especificar.
Es posible incluso indicar diferentes redondeados para las distintas esquinas.
Utilizaremos la siguiente propiedad: border-radius

  • border-bottom-left-radius; Tamaño para redondear esquina inferior izquierda
  • border-bottom-right-radius; Esquina inferior derecha
  • border-top-left-radius; Esquina superior izquierda
  • border-top-right-radius; Esquina superior derecha

Veamos un ejemplo:

<style type="text/css">
		
	h4.border_3 {
		border: 5px groove grey;
		border-radius: 10px 30px 0px 30px;
	}		

</style>
	
<h4 class="border_3">Esto es h4 con bordes redondeados</h4>

Margin

Margin (Márgenes)

El margen es el espacio que está después del borde, es el espacio más exterior y lo separa de otros elementos.
Los valores pueden expresarse en cualquiera de las unidades admisibles en CSS1: px, pt....
Las cuatro propiedades que controlan los márgenes alrededor de un elemento son:

  • margin-top
  • margin-bottom
  • margin-left
  • margin-right

Padding

Padding (Relleno)

Es el espacio entre el contenido y el borde de la caja.
Al igual que con los márgenes, se pueden usar unidades de longitud o porcentajes.
Los valores que pueden tomar son:

  • padding-top
  • padding-bottom
  • padding-left
  • padding-right

Veamo un ejemplo definiendo una caja (DIV)

<style type="text/css">

div.border_4 {
	margin-top: 5px; 
	margin-right: 50px;
	margin-bottom: 40px;
	margin-left: 50px;
	border: 2px solid red;
	padding-bottom: 25px;
	background-color: black;
	color: white;
}

</style>

Esto es un párrafo sin formato (formato estándard) antes del DIV
