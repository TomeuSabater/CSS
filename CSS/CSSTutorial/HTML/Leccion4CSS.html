Existe un orden de aplicación para el CSS si este está definido a diferentes niveles:

  1. CSS a nivel de etiqueta, es el que más prioridad tiene, reescribe cualquier estilo de nivel superior
  2. CSS a nivel de header, reescribe cualquier estilo de nivel superior
  3. CSS a nivel de fichero .css externo, reescribe cualquier estilo a nivel superior
  4. CSS por defecto que aplica el navegador, es el de menor prioridad, pero el que se aplica si no existe otro
