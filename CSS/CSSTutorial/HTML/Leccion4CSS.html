Orden de Aplicación de los Estilos: Cascading Order

Existe un orden de aplicación para el CSS si este está definido a diferentes niveles: (de mayor a menor prioridad)

  1. CSS a nivel de etiqueta (Inline), es el que más prioridad tiene, reescribe cualquier estilo de nivel superior
  2. CSS a nivel de header (Internal), reescribe cualquier estilo de nivel superior
  3. CSS a nivel de fichero .css externo (External), reescribe cualquier estilo a nivel superior
  4. CSS por defecto que aplica el navegador, es el de menor prioridad, pero el que se aplica si no existe otro

El CSS se denomina "Cascade" porque se aplica en cascada.
Se puede definir CSS Inline, Intenal y External sobre una misma página y el formato final siempre sigue el mismo orden:

En el siguiente ejemplo tenemos definido los siguiente:

  • <h1>Estilo de Navegador</h1> sin ningún css definido sobre este tag
  • Un fichero .css con el siguiente contenido (External): 
    				  <link rel="StyleSheet" href="../CSS/Leccion4CSS.css" type="text/css">
				  @charset "UTF-8";
		
					/* Definimos los headers de colores */
					h2 {color:#ff0000}
					h3 {color:#ff0000}
					h4 {color:#ff0000}
  • Una cabezera con el siguiente contenido (Internal): 
    					<style type="text/css">
		   			h3 {color:#00ff00}
		   			h4 {color:#00ff00}
					</style>
  • Finalmente, un tag definido de la siguiente manera (Inline):
    					  <h4 style="color:#0000ff">Estilo de etiqueta</h4>

El resultado final es como sigue: (código y resultado)

			<h1>Estilo de Navegador</h1>
		  	<h2>Estilo de fichero css</h2>
		  	<h3>Estilo a nivel de header</h3>
		  	<h4 style="color:#0000ff">Estilo de etiqueta</h4>

Al poner definir prioridades, podemos hacer los siguiente:

  • Generar un fichero .css en modo External para dar formato y estilo a toda la web de manera general.
  • Utilizar el css en modo Internal para dar formato a las páginas consideradas especiales porque no siguen el formato y estilo general.
  • Utilizar el css en modo Inline para dar formato a los tags o elementos específicos de una página que necesitan de un formato y estilo puntual.
